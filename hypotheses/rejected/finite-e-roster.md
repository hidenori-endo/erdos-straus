# Finite e-roster program

- status: rejected（有限 roster は原理的に 1970 年の既知結果に劣る）
- source: 本セッションの数値検証。関連: [Type I e-roster](../live/typeI-e-roster.md)

## 主張

「有限個の e（と有限個の合同条件）で ES を証明する」route は閉じている。

理由は密度の階層。[Type I e-roster](../live/typeI-e-roster.md) の実測で、
roster サイズ R に対する例外集合は

    #{p <= X : e ≤ E の Type I がすべて失敗}  ≍  X (log X)^{-(1+R/2)}

固定 R では log の冪の節約しか得られない。一方 Vaughan (1970) の既知の上界は

    #{n <= N : 4/n が表現できない}  <<  N exp(-c (log N)^{2/3})

で、任意固定の R に対する `X (log X)^{-(1+R/2)}` より遥かに小さい。
つまり有限 roster の議論は **1970 年の技術に厳密に劣る**。新しい上界も、まして証明も出ない。

全素数を覆うには roster を X とともに伸ばす必要があり、実測の幾何級数的減衰
（e を 1 個足すごとに残余が約 0.45 倍、ただしこの比自体も (log X)^{-1/2} で縮む）から
必要サイズは `R ≍ 2 log X / log log X` 程度。X=1e7 で R≈12、実際に必要だったのは e≤111（28 個）。

## 残るもの

- 定理A（p ≢ 1 mod 24 の完全解決、e∈{1,3,7} と (a,b)∈{(1,1),(1,2),(1,6)}）は正しく、
  最小の明示 witness として価値がある。ただし古典的に既知。
- (log X)^{-1/2} 則の定数 1.68 は安定しており、例外集合の**下からの**振る舞いの記述としては有用。
