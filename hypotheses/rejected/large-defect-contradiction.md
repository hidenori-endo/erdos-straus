# Large defect 自体を矛盾にする

- status: rejected
- source: 2026-09-03 会話の追加検証

## 主張

counterexample なら stabilizer defect index が大きくなるため、`q→∞` の large defect
から矛盾が得られる。

## 反証

`|R_q|≤τ(C_q²)` から defect index は固定 p で q^{1-o(1)} 以上になる。これは large q
で signed box が疎になる一般現象であり、counterexample に特有の圧力ではない。
非自明なのは prescribed NR atoms と exact target placement の相関である。
