# 数学的仮説の一覧

## Live / usable

- [Type II bound](live/typeII-bound.md): p >= 11k - 36。会話内では無条件結果として扱う。
- [Type I H bound](live/typeI-H-bound.md): H = d(b-a)^2 >= 22 と上側k bound。
- [Unique Peak / Central Peak / Reciprocal Mirror](live/unique-peak-candidate.md): 3定理とも真、証明つき。ただし ES への効き目は無い。
- [Type I e-roster](live/typeI-e-roster.md): Type I の正確な形 4abd=ep+1, e|d(a+b)。定理A (p≢1 mod 24 の完全解決) と roster の漸近則。
- [Type II exact](live/typeII-exact.md): Type II の厳密パラメータ化。Type I と同型。
- [min-e の記録は極値の産物](live/min-e-extreme-value.md): max min-e=111 (p=21841) が 10^5〜10^7 で動かない理由は極値統計。付随して `e ≡ 7 (mod 8)` は `M_e` が偶数になるため系統的に易しい（失敗率 0.57 vs 0.75）。
- [Global branch-covering problem](live/global-branch-covering.md): 全admissible shiftでType I/II targetを逃れられないことを示す本命課題。
