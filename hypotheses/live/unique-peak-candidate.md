# Unique Peak / Central Peak / Reciprocal Mirror（3定理とも成立、証明つき）

- status: **verified — 3つとも真。証明を与えた。ただし ES への効き目は無い**
- 由来: 3定理の主張（と証明スケッチ画像4枚）は会話外の公開投稿から持ち込まれたもの。
  投稿側の検証範囲は `q < 4000` の計算確認、文献的新規性は未調査と自称していた。
  投稿本文・画像はこのリポジトリには含めない。**以下の定式化・証明・数値検証はすべて本セッションで

- verified: 本セッション（Q <= 3000、反例 0）

## 設定

`q = 4Q - 1`、`mu_q(t) = #{(s1,s2) : s1,s2 | Q, -4 s1 s2 ≡ t (mod q)}`。

基本事実（以下すべてで使う）:
- `4Q = q+1 ≡ 1 (mod q)` なので **`4^{-1} ≡ Q (mod q)`**。
- `gcd(Q,q) = gcd(Q, 4Q-1) = 1` なので Q の約数はすべて mod q で可逆。
- Q の約数は `[1,Q]` にあり `Q < q` なので、**相異なる約数は mod q で相異なる**。

## 定理1: Central Peak — 真（証明は画像より簡単）

`mu_q(t) <= tau(Q)`、かつ `mu_q(-1) = tau(Q)`。

証明: t を固定すると、各 `s1|Q` に対し `s2 ≡ -t (4 s1)^{-1} (mod q)` は一意に定まる。
Q の約数は mod q で相異なるので、この類に入る約数は高々1個。よって `mu_q(t) <= tau(Q)`。
`t = -1` では任意の `s|Q` に対し `-4·s·(Q/s) = -4Q ≡ -1` なので tau(Q) 個すべてが当たる。∎

**画像1/4 の証明のコアは誤り。** 「`d | Q^2` かつ `d ≡ Q (mod q)` なら両辺が q 未満なので d=Q」
と書いてあるが、`Q^2 ≈ q^2/16 >> q` なので d は q を超えうる。結論は上の議論で別途正しい。

## 定理2: Reciprocal Mirror — 真（画像3の証明は正しい）

`mu_q(t) = mu_q(t^{-1})`。対合 `(s1,s2) -> (Q/s1, Q/s2)` が `t = -4 s1 s2` を
`t' = -4Q^2/(s1 s2)` に送り、`t t' = 16 Q^2 = (4Q)^2 ≡ 1 (mod q)`。∎

## 定理3: Unique Peak — 真。ただし画像1の証明は成立しない。以下が正しい証明

主張: `mu_q(t) = tau(Q)` ならば `t ≡ -1 (mod q)`。

条件を `s1 s2 ≡ c := -t·4^{-1} (mod q)` と書く。`mu_q(t)=tau(Q)` は
「任意の約数 `s|Q` に対し相手 `sigma(s)|Q` が存在して `s·sigma(s) ≡ c`」と同値。

1. `s=1`: `c ≡ c0 := sigma(1)`、`c0` は Q の約数で `c0 ∈ [1,Q] ⊂ [1,q)`。
2. `s=Q`: `Q·sigma(Q) ≡ c0`。`Q ≡ 4^{-1}` なので `sigma(Q) ≡ 4 c0`。
3. **`c0 = Q` の場合**: `-t·4^{-1} ≡ Q ≡ 4^{-1}` より `t ≡ -1`。← 中央のピーク。
4. **`c0 < Q` の場合**: `4c0 <= 4Q-4 < q` なので整数として `sigma(Q) = 4 c0`、よって `4 c0 | Q`。
5. **上昇帰納法**: `2^k c0 | Q` (k>=2) を仮定。`2^{k-1} | Q` なので `s = Q/2^{k-1}` は約数で、
   `s ≡ 4^{-1} 2^{-(k-1)} = 2^{-(k+1)}`。よって `sigma(s) ≡ 2^{k+1} c0`。
   `2^k c0 <= Q` より `2^{k+1} c0 <= 2Q < q` なので整数として `sigma(s) = 2^{k+1} c0`、
   したがって `2^{k+1} c0 | Q`。
6. ゆえに任意の k で `2^k c0 | Q`。Q は有限なので矛盾。∎

画像1の連鎖 `d<Q => 4d|Q => 2d|Q => 2c≡1` のうち `4d|Q => 2d|Q` は自明で何も生まず、
`2c≡1` を導く根拠も無い。正しいのは上の **2進の上昇連鎖**。

## 数値検証（本セッション）

- Q <= 3000（q <= 11999）で 定理1・2・3 すべて反例 0。画像の主張する検証範囲（q<4000, q<1500）より広い。
- Q <= 1200 で「最大値到達は 1200 件、すべて t=-1、証明のステップに反する件数 0」。

## ES への効き目：無い

ES が要求するのは roster の **台**（`mu_q(t) >= 1` となる t、すなわち「当たる剰余類」）であって、
最大値ではない。台の大きさは高々 `tau(Q)^2` なので、被覆率 `<= tau(Q)^2 / q -> 0`。実測:

| Q | q=4Q-1 | tau(Q) | mu>=1 のクラス数 | 被覆率 | mu=0 のクラス数 | peak 高 |
|---|---|---|---|---|---|---|
| 6 | 23 | 4 | 9 | 39.1% | 14 | 4 |
| 60 | 239 | 12 | 41 | 17.2% | 198 | 12 |
| 210 | 839 | 16 | 81 | 9.7% | 758 | 16 |
| 840 | 3359 | 32 | 173 | 5.2% | 3186 | 32 |
| 2310 | 9239 | 32 | 243 | 2.6% | 8996 | 32 |

Q が伸びるほど roster が覆う剰余類の割合は 0 に落ちる。3定理は「一番高い棒」の位置と対称性を
記述するもので、ES に必要な「どの棒が 0 でないか」には何も言わない。
`-1` は最も当たりやすい＝**最も易しい**クラスであり、hard prime は逆側にいる。
