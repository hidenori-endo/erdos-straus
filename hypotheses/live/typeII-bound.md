# Type II bound

- status: usable / treated as an unconditional result in the conversation

For normalized Type II parameters, the hard-prime conditions force

~~~
p >= 11k - 36
~~~

and hence k <= (p + 36)/11. Therefore the upper corridor beyond this threshold is Type-I-only.

This is a bound on the Type II region, not a solution of the full Erdős–Straus conjecture.
