# k=11 の class 分割は mandatory seed `15 | C_11` で決まる

- status: **proved**（初等的、range-free）+ 数値裏付け
- source: 2026-09-01 closure 訂正後の追加検証

## 背景

訂正後の atlas で「miss ⇔ `C_k` の全素因子が p-QR」が成立するのは 21 組だけで、
`k=11` はそのうち 3 class（`h = 169, 289, 529`）でのみ成立する。
`k=3,7,15` が全 class で成立するのに対し、`k=11` だけが class で割れる。
その原因を特定する。

## 分岐の正体

`k=11` は `840` を割らないので center fiber は `Z/11Z` 全体であり、class 差は
center からは来ない。差は **mandatory seed** だけである。
`seed = gcd(210, (h+k)/4)` は

| `h` | `(h+11)/4` | seed | 成立 |
|---:|---:|---:|:--|
| 1 | 3 | 3 | × |
| 121 | 33 | 3 | × |
| 361 | 93 | 3 | × |
| 169 | 45 | 15 | ○ |
| 289 | 75 | 15 | ○ |
| 529 | 135 | 15 | ○ |

つまり成立するのは `3 | C_11` に加えて `5 | C_11` も強制される 3 class である。

## 補題（証明済み）

~~~
15 | C_11 かつ C_11 が p-NR 素因子を持つ  ⇒  shift 11 は hit する。
~~~

すなわちこの 3 class では miss ⇒ pure が成り立ち、
[QR-support 十分性](qr-support-sufficiency.md)と合わせて同値になる。

### 記号

`mod 11` で `QR = {1,3,4,5,9}`、`NR = {2,6,7,8,10}`。
Type I target は `t₁ = -4^{-1} = 8`、Type II target は `t₂ = -C_11 mod 11`。
`S` を `C_11` の約数の `mod 11` 剰余集合、`D = S ∩ QR` とする。

### 証明

`15 | C_11` より `S ⊇ {1, 3, 5, 15} ≡ {1, 3, 5, 4}`。
`C_11` の p-NR 素因子を `r` とする。

1. **`r ≢ 7` なら hit。** `t₁ = 8 ∈ r·{1,3,4,5}` ⟺ `r ∈ 8·{1,3,4,5}^{-1} = 8·{1,4,3,9} = {8,10,2,6}`。
   NR は `{2,6,7,8,10}` なので、`r ≠ 7` の NR はすべてこの集合に入り `t₁` を踏む。
   逆に `8/7 = 8·8 = 9 ∉ {1,3,4,5}` なので `r = 7` だけが `t₁` を外しうる。

2. **NR 因子は重複度込みで 1 個だけ。** NR 因子を 2 つ使うと（1 より両方 `≡ 7`）
   積が `49 ≡ 5` となり `S ⊇ 5·{1,3,4,5} = {5,4,9,3}`、すなわち `9 ∈ D` で
   `D = QR` 全体。すると `7·9 = 63 ≡ 8 = t₁ ∈ S` で hit。

3. **残るのは `C_11 = 15·m·7^1`（`m` は QR-supported）の形だけ。**
   このとき `C_11 ≡ 4·m·7 = 28m ≡ 6m`、`t₂ = -6m ≡ 5m`。
   `m ∈ QR` なので `t₂ = 5m ∈ 5·QR = QR`。
   `t₂` を外すには `t₂ ∉ D ⊇ {1,3,4,5}`、つまり `t₂ = 9`、すなわち `m ≡ 4 (mod 11)`。

4. **矛盾。** `m ≡ 4` かつ `m | C_11` なので `5m` も `C_11` の約数で、
   `5m ≡ 20 ≡ 9 ∈ D`。ゆえに `t₂ = 9 ∈ S` となり hit。

以上より非 pure な miss は存在しない。∎

## 反対側（seed 3 の 3 class）

seed が `3` だけだと 1 の段階で `S ⊇ {1,3}` しかなく、`t₁ = 8 ∉ r·{1,3}` は
`r ∉ {8, 8·3^{-1}} = {8,10}`、つまり `r ∈ {2,6,7}` で満たされる。実際に
`C_11 = 3·r`、`r ≡ 2 (mod 11)` の形の反例が各 class にある。

| `h` | 最小反例 `p` | `C_11` | `S` | `t₁` | `t₂` |
|---:|---:|---|---|---:|---:|
| 1 | 2,521 | 3·211 | {1,2,3,6} | 8 | 5 |
| 121 | 14,401 | 3·1201 | {1,2,3,6} | 8 | 5 |
| 361 | 1,201 | 3·101 | {1,2,3,6} | 8 | 5 |

`p < 10^8` の監査では逆に `h = 169, 289, 529` の非 pure miss は 0 件で、補題と
一致する。さらに補題を抽象化した検証（余分な素因子剰余の多重集合を長さ 8 まで
全探索）でも反例 0。

## 含意

class 分割は「seed が `ker χ` を飽和するか」ではなく、**seed の約数集合
`{1,3,5,4}` が `QR` の中でどれだけ広いか**で決まる。`{1,3}` では 3 個の NR が
`t₁` を外せるのに対し、`{1,3,4,5}` では `r = 7` の 1 本に絞られ、それも
`t₂` で潰れる。[k=35 の棄却例](../rejected/k35-pure-support-theorem.md)で
「seed が `ker χ` を飽和する」が必要条件になり得なかった理由もここにある。
