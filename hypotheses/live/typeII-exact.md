# Type II exact（厳密パラメータ化）

- status: live（同値性は定理。解集合レベルで検証済み）
- source: 本セッション

## 同値条件

`4/p = 1/x+1/y+1/z` で `p|y, p|z, p∤x`（Type II）は次と厳密に同値:

    ∃ A,B,h >= 1, gcd(A,B)=1, ∃ s>=1 で s | (A+B),  かつ  p = 4hAB - s
    x = hAB,  y = p·h·A·(A+B)/s,  z = p·h·B·(A+B)/s

`4 | p+s` が必要（p≡1 mod 4 では s≡3 mod 4）。`N_s := (p+s)/4` と置くと `hAB = N_s` なので

    Type II  <=>  ∃ s ≡ -p (mod 4), s <= (p+4)/3 で、互いに素な A,B が
                  AB | N_s かつ A+B ≡ 0 (mod s) を満たす

**Type I と完全に同じ形**で、`M_e=(ep+1)/4` が `N_s=(p+s)/4` に替わっただけ。
副産物: `x = hAB = N_s = (p+s)/4` なので **x は A,B の取り方に依らず、逆に s = 4x-p**。

## 検証

- p<400 の素数 76 個で、素朴全探索による Type II **解集合そのもの**とパラメータ化が完全一致（不一致 0）。
  この範囲では Type II 解が空の p は 0 個。
- s=3 の 1行判定「`N_3=(p+3)/4` が 2 mod 3 の素因子を持つ」を p<50000 の該当 2549 個で検証、不一致 0。
  Type I の e=3（`(3p+1)/4` が 2 mod 3 の素因子を持つ）と字面まで同型。
- s>=7 では潰れない。最小例 p=173: `N_7=45=3^2·5` の約数に 6 mod 7 は無いが `(A,B)=(9,5)`、`9+5=14`。

## Type I の例外集合との関係（サブエージェント計測、p<10^6）

- Type I の e∈{3,7} 失敗 1737 個は **すべて Type II で解ける**（最小 s は最大 59）。
- ただし境界を揃えると: Type I e<=7 失敗 1737、Type II s<=7 失敗 989、**両方失敗 331**。
  小さい e と小さい s の有限集合では覆えない。
- **重要**: Type II s<=7 の失敗集合の mod 840 の像は
  `{1, 121, 169, 289, 361, 529} = {1, 11^2, 13^2, 17^2, 19^2, 23^2}`、
  すなわち古典的に既知の hard class 6 個にちょうど一致する。
  Type II は古典的な壁を**再現するだけで越えない**。
