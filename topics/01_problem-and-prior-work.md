# 01. 問題設定と既存研究

## 中心問題

Erdős–Straus予想は、すべての整数 n >= 2 について

~~~
4/n = 1/x + 1/y + 1/z
~~~

を満たす正整数 x, y, z が存在するか、という問題である。会話の対象は主に、素数 p に対する解の構造と、そこから得られる合同条件・約数条件である。

## 既存PRの位置づけ

- PR #129 の基本戦略は、素数への帰着、分母内でのpの位置による分類、Egyptian fraction条件の約数化という既知の流れと重なる。
- PR #133 は、#129をErdős–Straus予想の解決と評価したことを訂正する内容であり、未解決性を解消していない。
- PR #134 は、F1のような狭い族が一般解を代表するという期待を否定する方向の資料である。

## 現在の結論

有限範囲の計算成功や、特定族の被覆は、全素数に対する普遍定理ではない。Type I / Type IIを同時に扱う必要がある。
