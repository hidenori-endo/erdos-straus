## 1. 検証した仮説

> リポジトリの監査・閉包が使う「箱」`Div(C_k)`（`C_k` の約数の `mod k` 剰余）は
> ES 解の判定に対する部分箱にすぎず、正しい箱は `Div(C_k²)` である。
> したがって 09-01 の「`r²` 遷移はバグ」は逆であり、`k=35` の pure-support 定理は復活する。

## 2. 正しい箱の導出（証明）

解 `4/p = 1/x+1/y+1/z` で `p ∤ x` なる分母 `x` を取る（3 分母全てが `p` の倍数だと
`4 = 1/a+1/b+1/c` となり不可能なので必ず存在する）。`x > p/4` なので
`k := 4x - p ≥ 3`、`k ≡ -p ≡ 3 (mod 4)`、`x = C_k = (p+k)/4`。残り 2 項は

~~~
1/y + 1/z = 4/p - 1/C_k = k/(pC_k)   ⇔   (ky - pC_k)(kz - pC_k) = p²C_k².
~~~

- **Type II** (`y=py'`, `z=pz'`): `(ky'-C)(kz'-C) = C²`。`D := ky'-C` は `C²` の約数で
  `D ≡ -C (mod k)`。逆に `D | C²`, `D ≡ -C` から `y' = (D+C)/k`, `z' = (C²/D + C)/k` が
  正整数になり解を与える。
- **Type I** (`y=py'`, `p ∤ z`): `p(ky'-C)(kz-pC) = p²C²`。`p ∤ (kz-pC)` なので
  `p | ky'-C`、`D := (ky'-C)/p` は `C²` の約数。`pD ≡ -C` と `p ≡ 4C (mod k)` から
  `D ≡ -1/4 (mod k)`。逆も同様に復元できる。

よって

~~~
ES(p)  ⇔  ∃ k ≡ 3 (mod 4):  Div(C_k²) mod k  ∋  -1/4  または  -C_k.
~~~

`Div(C_k²) mod k = S·S`（`S = Div(C_k) mod k` の積集合）であり、`S` は `D ↦ C_k/D` で
対称なので、これは「互いに素な約数 `A,B | C_k` で `A ≡ -B` または `A ≡ -pB (mod k)`」
という signed box の言い方と同値である。09-03 addendum §3–4 が使っていた
「signed exponent vector」「`|R_q| ≤ τ(C_q²)`」はこの正しい箱に対応していた。

`code/box_check.py` で `p<700` の全素数の全解 1,262 (解, x) 組について、
解 → 箱 hit と箱 hit → 解の両方向を assert で確認した（違反 0）。同時に
**`Div(C_k)` では miss だが `Div(C_k²)` では hit の `(p,k)` が 266 組**ある
（最小例 `p=37, k=11, C=12=2²·3`）。

## 3. 09-01 訂正の何が誤りだったか

09-01 は遷移 `S → S ∪ rS ∪ r²S` を「指数 1 の素因子に実在しない約数 `r²` を混ぜる」
として `S → S ∪ rS` に変えた。しかし箱が `C_k²` の約数である以上、指数 1 の `r` に
対しても `r²` は実在する約数であり、素因子 1 個の消費で指数上限は 2 増える。
つまり **元の `r²` 遷移が正しく、訂正後の遷移が部分箱**だった。

部分箱は hit を取りこぼす方向にしか誤らない（部分箱 hit ⇒ 真の hit）。そのため
「miss かつ非 pure」が実際より多く数えられ、偽の反例が生まれた。09-01 の
`k=35` 反例 `p=21121`（`C_35 = 3·41·43`、`S = {1,3,4,6,8,13,18,24}`）は、
`S·S ∋ 4·24 = 96 ≡ 26 = t₁` なので真の箱では **Type I の hit** である
（`D = 3²·41·43² = 682,281 ≡ 26 (mod 35)`）。

09-01 が「閉包と実素数監査が完全一致」としたのは、両方が同じ部分箱を使っていた
からで、箱そのものの正しさは検証していなかった。

## 5. 定理の状態

- [QR-support 十分性](../hypotheses/live/qr-support-sufficiency.md)（pure ⇒ miss）は
  正しい箱でもそのまま成立する。`S ⊆ ker χ` なら `S·S ⊆ ker χ` であり、target は
  どちらも `χ = -1` だからである。`p < 10^8`, `k ∈ {3,7,11,15,19,31,35,47,59,71}` で
  `pure かつ hit` は 0 件。
- [k=11 の seed 15 補題](../hypotheses/live/k11-seed15-lemma.md) は部分箱で hit を
  示しているので正しい箱でも hit。反対側の反例（`C_11 = 3·r`, `r ≡ 2`）は正しい箱でも
  miss（`p<10^8` の最小 witness は変わらず `p = 2521, 14401, 1201`）。
- [k=35 pure-support 定理](../hypotheses/live/k35-pure-support-theorem.md) は
  rejected から live に戻す。`h = 121, 361` で range-free に成立。

## 6. 何が annihilation を決めるのか（正しいデータでの再点検）

`k ≤ 135`（204 組）について、seed の生成する部分群 `⟨seed⟩`、center 固定
（`k | 840`）、`t₁ = t₂` の 3 条件で成否を分類すると

| `⟨seed⟩ ⊇ ker χ` | center 固定 | `t₁ = t₂` | 成立 | 不成立 |
|:-:|:-:|:-:|---:|---:|
| × | × | × | 0 | 51 |
| × | × | ○ | 0 | 10 |
| ○ | × | × | 10 | 88 |
| ○ | × | ○ | 1 | 20 |
| ○ | ○ | × | 9 | 3 |
| ○ | ○ | ○ | 11 | 1 |

09-01 で「必要条件にならない」と棄却された **「seed が `ker χ` を生成する」は、
正しい箱では成立 31 組（`p<2·10^6` 段階）すべてで満たされる必要条件**に戻る。
十分ではない（満たしても 112 組が不成立）。center が固定される `k ∈ {3,7,15,35}` では
24 組中 20 組が成立し、外れるのは `k=35` の `h ∈ {1,169,289,529}` だけである。
`h=1` は常に `c ≡ 1/4`、すなわち `t₂ = t₁` で target が 1 本に潰れる。

次に必要なのは

1. 「`⟨seed⟩ ⊉ ker χ` ⇒ 非 pure な miss が存在する」の証明（正しい箱での必要性）。
2. `⟨seed⟩ ⊇ ker χ` かつ center 固定の 24 組で、`k=35` の 4 class だけが落ちる理由。
   center `c` と seed から決まる有限個の miss state（`h=1`: 8、`169`: 3、`289`: 1、
   `529`: 2）を [k=11 補題](../hypotheses/live/k11-seed15-lemma.md)と同じ形で書き下す。
3. center が動く（`k ∤ 840`）場合の 10 組（`k=11` の 3、`19`、`31` の 3、`47` の 2、
   `59`）で、どの center fiber が生き残るかの分類。
