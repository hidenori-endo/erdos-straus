## 1. 何が壊れていたか

signed-box の状態遷移を、素因子 `r` の消費に対して

~~~
S -> S ∪ rS ∪ r²S
~~~

と定義していた。これは `r` の指数が 2 であることを前提にしており、指数 1 の
素因子に対して**実在しない約数 `r²` を状態に混ぜる**。約数集合が過大になると、
本当は target を外している配置が hit と判定されるので、`-1` character の miss が
実際より少なく数えられ、**偽の annihilation** が出る。

正しい遷移は素因子 1 個の消費に対応する

~~~
S -> S ∪ rS,   c -> c·r,   neg -> neg ∨ [χ(r) = -1]
~~~

の 1 段だけで、指数は反復適用で伸ばす。これで実在する全ての約数集合が到達可能に
なり、閉包が現実の over-approximation になる。

副次的に、旧実装には次の欠陥もあった（いずれも訂正済み）。

- mask が `unsigned __int128` 固定で、`k ≥ 131` が黙ってスキップされていた。
  「`k ≤ 300` を走査した」という記述は実際には `k ≤ 123` しか走っていない。
- witness 探索が深さ 2 固定で、かつ中間状態を**動く** Type II target `-c` で
  枝刈りしていた。どちらも miss を取り逃す方向に働く。
- center fiber を `jacobi(c,k)=+1` に限定していた。`k=15,35` では hard 条件から
  自動的に成り立つので無害だが、840 を割らない素因子を持つ `k` では正当な
  fiber を落とす。

## 2. character の補題（訂正なし・証明付き）

`r | C_k` なら `4C_k = p+k` より `p ≡ -k (mod r)`。`k ≡ 3 (mod 4)` なので
相互法則の符号が `(-1/r)` と相殺して

~~~
(p/r) = (-k/r) = (-1/r)(k/r) = (-1/r)² (r/k) = jacobi(r,k)
~~~

すなわち character は `r mod k` だけで決まる。`r=2` のときも `2|C_k` から
`p ≡ -k (mod 8)` が従うので、Kronecker 記号として同じ等式が成り立つ。
`k ≤ 203`、`p < 2·10^5` の `(p,r)` 1,183,204 組で mismatch 0
（`closure --selftest`）。

## 3. QR-support 十分性は定理（新規・証明）

`k ≡ 3 (mod 4)` より `χ(-1) = jacobi(-1,k) = (-1)^{(k-1)/2} = -1`、また
`jacobi(4,k) = +1`。したがって

- `χ(t₁) = χ(-1/4) = χ(-1) = -1` — Type I target は**常に**非剰余。
- `C_k` の全素因子が p-QR なら `jacobi(C_k,k)=+1`、つまり `c ∈ ker χ` なので
  `χ(t₂) = χ(-c) = χ(-1)χ(c) = -1` — Type II target も非剰余。

一方、全素因子が QR なら全約数もその積なので `S ⊆ ker χ`。よって `t₁,t₂ ∉ S`。

~~~
定理: C_k の全素因子が p-QR ならば shift k は miss する。
対偶: shift k が hit するならば C_k は p-NR の素因子を持つ。
~~~

`k = 3,7,...,403` の 101 shift × hard prime 4,519 個 = 456,419 件で
`pure かつ hit` は 0 件。

## 4. 逆向き（miss ⇒ pure）が成り立つ `(k,h)` の完全な表

逆向きは shift と hard class に強く依存する。`k ≡ 3 (mod 4)`、`k ≤ 403` の
101 shift × 6 class = 606 組を `p < 2·10^6` で監査したところ、成立するのは
**21 組だけ**である。

| `k` | 成立する hard class `h = p mod 840` |
|---:|---|
| 3 | 1, 121, 169, 289, 361, 529（全 class）|
| 7 | 1, 121, 169, 289, 361, 529（全 class）|
| 11 | 169, 289, 529 のみ |
| 15 | 1, 121, 169, 289, 361, 529（全 class）|

`k ≥ 19` は 1 組も成立しない。この 21 組は `p < 10^8` の hard prime 179,468 件でも
mismatch 0（下表）、かつ有限閉包でも range-free に確認された（`k=11` の
`h=1,121,361` は closure でも実素数でも不成立で、両者は完全に一致する）。

| `k` | hard p | exact miss | pure miss | 食い違い |
|---:|---:|---:|---:|---:|
| 3 | 179,468 | 97,374 | 97,374 | 0 |
| 7 | 179,468 | 100,392 | 100,392 | 0 |
| 11（3 class）| 89,679 | 26,556 | 26,556 | 0 |
| 15 | 179,468 | 98,684 | 98,684 | 0 |

`k=15` の値は [追加検証ダイジェスト](2026-09-01-addendum.md) §3 の
179,468 / 98,684 / 98,684 / 0 と桁まで一致し、独立に再現できた。

## 5. `k=15` の証明証拠

完全閉包（枝刈り無し）は 42 状態で閉じ、center fiber に到達する 8 状態のうち
miss はちょうど 2 個。その約数剰余集合は必ず

~~~
S ⊆ {1,2,4,8} = ker χ ⊂ (Z/15Z)^×
~~~

に収まる。`non-pure miss = 0` と `pure かつ hit = 0` が同時に立つので、6 hard class
すべてで `k=15 が miss ⇔ C_15 の全素因子が p-QR` が両方向の同値になる。

## 6. `k=35` は反証

class 121 の監査値は、hard prime 29,900 と pure miss 18,080 が先行報告と一致する
一方、**exact miss は 20,298** で、`miss かつ非 pure` が 2,218 件実在する。
先行報告が両者を 18,080 で一致させていたのは、exact miss 側を `r²` バグ入りの

## 7. 旧 criterion の帰結

`k=35` が落ちたことで、「mandatory seed が QR kernel を飽和すれば消える」という
方向の必要条件は十分性を失う。`k=35` は `⟨3⟩ = ker χ`（位数 12）を飽和し、かつ
`35 | 840` なので center fiber が 1 点という条件も満たすが、annihilation は
起きない。逆に成立する 21 組は composite に限らず `k=3,7` を含むので、composite
shift だけを見ていた旧 atlas の枠組み自体が狭かった。
