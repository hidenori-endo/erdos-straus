## 1. E が偶数になる shift（証明）

hard prime `p` は `p ≡ 1 (mod 8)` かつ `p` が `mod 3, 5, 7` で平方なので、
`r | C_k` の character `χ(r) = (p/r)` の積は

~~~
χ(C_k) = jacobi(p, k) = ∏_{q | k} (p/q)^{v_q(k)}
~~~

で、`q ∈ {3,5,7}` の因子は `+1`。従って **`k` の奇数冪の素因子が全て `{3,5,7}` に
入る shift** では `χ(C_k) = +1`、すなわち `C_k` の p-NR 素因子の個数 `E`（重複込み）は
常に偶数である。該当する `k ≤ 403` は

~~~
3, 7, 15, 35, 27, 63, 75, 147, 243, 315, 363
~~~

（`363 = 3·11²` は `(p/11)²` で入る）。これらでは
[QR-support 十分性](../hypotheses/live/qr-support-sufficiency.md)が
「hit するなら p-NR 素因子が **2 個以上**」に強まる。

## 2. center 固定 shift の annihilation は有限の場合分けで証明できる

`k | 840`、`k ≡ 3 (mod 4)` は `k ∈ {3, 7, 15, 35}` で、center `c` は class ごとに 1 点。
§1 より非 pure な `C_k` は NR 剰余 `r₁, r₂`（同じ素数の 2 乗でもよい）を含み、
残りを `m = C_k/(seed·r₁·r₂)` とすると `m ∈ Q` で、真の箱 `Div(C_k²)` は必ず

~~~
B(r₁, r₂, m) = Div(seed²) · {1, r₁, r₁²} · {1, r₂, r₂²} · {1, m, m²}
~~~

を含む（`E ≥ 4` や `m` が合成数の場合は単調性で吸収される）。従って
全 `(r₁, r₂) ∈ NR²` で `B ∋ t₁` または `B ∋ t₂` なら「非 pure ⇒ hit」。

`code/even_e_cases.py` の結果（`k=35` は 78 組の `(r₁ ≤ r₂)`）:

これで center 固定の成立 20 組は全て、閉包モデルに依らない初等証明
（有限検査つき）を持つ。`k=35` の失敗 class の miss 組は実素数の最小 witness と一致する:

`k=35` の指数表示: `Q = ⟨3⟩`（位数 12）、`NR = 2·Q`。`t₁ = 2·3⁹`、
`h=121` では `t₂ = 2·3⁵`、`r_i = 2·3^{a_i}`、`m = 3^μ`、`μ ≡ -(1+a₁+a₂) (mod 12)`。

これが `mod 12` で 9 または 5 を必ず含む、というのが `h=121` の主張である。

## 3. `⟨seed⟩ ⊇ ker χ` は必要条件（構成的証明）

閉包の到達状態として次が作れる（`h₀ ∈ H` は任意、生成元を余分に消費して調整）。

- **E1**: `S = H ∪ rH ∪ r²H`、`c = h₀ r`（`r` NR）。`t₁` は NR なので `rH` でしか
  踏めず、`t₂ = -h₀r` は QR なので `H ∪ r²H` でしか踏めない。よって
  ~~~
  miss ⇔ r ∉ (-H) ∪ (-(1/4)H),   fiber ⇔ r ∈ H·F
  ~~~
- **E2i**: `r' = r⁻¹h` を足して `S = H ∪ r^{±1}H ∪ r^{±2}H`、`c = h₀ ∈ H`。
  ~~~
  miss ⇔ r ∉ (-H) ∪ (-(1/4)H) ∪ (-4H),   fiber ⇔ F ∩ H ≠ ∅
  ~~~
- **E2g**: `S = H·{1,r,r²}·{1,r',r'²}`、`c = h₀rr' ∈ F` を総当たり。

**命題（`k` に依らない）**: `gcd(k, 210) = 1` なら `F = G` なので、
`[Q : H] ≥ 3`、または `[Q : H] = 2` かつ `4 ∈ H` なら E1 が通り、`(k,h)` は
annihilate しない（NR 類は `H` の `[Q:H]` 個の剰余類からなり、禁止されるのは
`-H` と `-(1/4)H` の高々 2 個）。

`k ≤ 403` で `H ⊉ Q` の 217 組の内訳:

| 構成 | 組数 |
|---|---:|
| E1 | 181 |
| E2i | 25 |
| E2g | 11（`k = 75, 147, 315` の seed 1）|
| 未 cover | **0** |

E1 が通らない 36 組は全て §1 の「E 偶数」shift（`27, 63, 75, 147, 243, 315, 363`）で、
`c ∈ Q` が強制されるため E1 が原理的に不可能な組である。命題の適用範囲は
`gcd(k,210)=1` かつ index ≥ 3 の 81 組と index 2 の 2 組（`4 ∈ H`）、
`gcd(k,210)=1` で `[Q:H]=2, 4 ∉ H` の組は `k ≤ 403` に存在しない。

以上で、`k ≤ 403` では

~~~
(k,h) が annihilate する  ⇒  ⟨seed⟩ ⊇ ker χ
~~~

が閉包の到達状態として証明され（実素数側は
[箱の訂正](2026-09-03-box-correction.md) §4 の witness）、一般 `k` では
`gcd(k,210)=1` の場合に命題の形で成り立つ。

## 4. 残る問題

- `⟨seed⟩ ⊇ ker χ` かつ center が動く 10 組（`k=11,19,31,47,59`）の証明。
  `k=11` と `k=19` は既存の補題で済むが、`k=31, 47, 59` は `Div(seed²) ⊊ Q` なので
  §2 の一様下界だけでは足りず、E1 状態（`E` 奇数）も扱う必要がある。
- `⟨seed⟩ ⊇ ker χ` を満たしながら不成立の 359 組（`k=23, 39, 55` など）を分ける
  第二の条件。`k=35` の 4 class の miss 組（§2 の表）が最小の例。
- `gcd(k,210) > 1` かつ `k ∤ 840` の場合の、fiber を含む `k` に依らない命題。
