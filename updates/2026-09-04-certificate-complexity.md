# 2026-09-04: 証拠複雑度と恒等式階層

[transport verdict](2026-09-04-transport-verdict-and-min-hit-shift.md) §6 で残した
数え上げ route の第一歩として、**「ES の証拠を出すのに `C_k` のどれだけを知る必要があるか」**
を定量化した。結果として、証拠の約数部分は常に小さく、律速は shift `k` の大きさだけである
ことが分かった。

再現コード: `code/cert_size.cpp`, `code/cert_complexity.cpp`, `code/tradeoff.cpp`。

## 1. 証拠の最小約数 `d(e)`

`e | C_k²` が `t₁ = -1/4` または `t₂ = -C_k` を `mod k` で踏むとき、`e | d²` かつ
`d | C_k` を満たす最小の `d` は素因数ごとに

~~~
d(e) = ∏ q^⌈a_q/2⌉      (e = ∏ q^{a_q})
~~~

である（`a_q ≤ 2 v_q(C_k)` なので `⌈a_q/2⌉ ≤ v_q(C_k)` は自動）。

`d(e)` が意味を持つのは、**`(k, d, e)` を固定すると条件が `p` の合同式になる**からである。

- `d | C_k` ⟺ `p ≡ -k (mod 4d)`
- `e ≡ t₂ (mod k)` ⟺ `p ≡ -4e (mod k)`（`t₁` 側も同様に `p mod k` の条件）

そして解 `(x,y,z)` は `p` の多項式で書ける。したがって

> `k ≤ K` かつ `d(e) ≤ D` で全ての hard prime を覆えることは、有限個の合同類による
> covering system ＝ 古典的な恒等式族で ES が証明できることと同値である。

実際、`K,D` が同時に有界にはならないことは次のように直接示せる。上限 `B` を固定し、
`840`、全 `k≤B`、全 `4d (d≤B)` の公倍数を `L` とする。Dirichlet の定理により
`p ≡ 1 (mod L)` なる素数は無限にある。この `p` に `k,d≤B` の証拠があったとすると、
`d|C_k` であり、`d` の全素因子 `q` は transfer により
`χ_k(q)=(p/q)=+1`（`q=2` は Kronecker 記号）となる。従って `e|d²` は `χ_k(e)=+1`。
一方 `p≡1 (mod k)` から `χ_k(C_k)=Jacobi(p,k)=+1` なので、Type I / II の両 target は
`χ_k=-1`。これは hit と矛盾する。

> **有界性否定補題.** 任意の `B` に対し `cert(p)>B` なる hard prime `p` が無限にある。

従って **測るべきは `cert(p)` の増大率**である。なお、この補題が否定するのは `k,d` の
同時有界性であり、`d` だけを固定して `k` を非有界に許す場合は否定しない。

## 2. `cert(p) = min_k max(k, d(e))`

`k` を昇順に走らせ `k ≥ best` で打ち切ると全 `k` を扱える（`code/cert_complexity.cpp`）。
`p < 10^9` の hard prime 1,587,581 個で:

| `cert ≤` | 16 | 32 | 64 | 128 | 256 | 512 |
|---|---:|---:|---:|---:|---:|---:|
| 累積割合 | 0.4608 | 0.9168 | 0.9882 | 0.9994 | 0.99999 | 1.0 |

- **幾何平均 `cert = 17.2`**（`p<10^8` でも 17.2 で不変）。
- decade 別最大: `10^3`→34, `10^4`→155, `10^5`→111, `10^6`→173, `10^7`→251, `10^8`→**395**。

## 3. トレードオフ表: 約数予算 `D` と必要 shift `k_D`

`k_D(p) = min { k ≡ 3 (mod 4) : ∃ e | C_k², e ≡ t₁ or t₂ (mod k), d(e) ≤ D }`

> **約数予算 `D = 64` で `p < 10^8` の全 hard prime が `k ≤ 1191` で覆われる。**
> `D = 256` なら `k ≤ 251`。逆に `D` を小さくすると必要な `k` が急激に伸びる。

つまり証拠に必要な「`C_k` の知識」はごく浅く、難しさは shift の探索範囲に集中している。
これは [min hit shift bound](../hypotheses/live/min-hit-shift-bound.md) が正しい定式化で
あることの裏づけである。

## 4. `D = 1` の恒等式とその失敗集合（証明済み）

`D = 1` は `e = 1`、すなわち `C_k ≡ -1 (mod k)` の場合で、完全に明示できる。

> **補題 2.** `p ≡ 1 (mod 4)` とし、`p + 4 = k·j` で `k ≡ j ≡ 3 (mod 4)` と書けたとする。
> `m = (j+1)/4`、`C = (p+k)/4` とおくと `C = km - 1` で
>
> ~~~
> 4/p = 1/C + 1/(pm) + 1/(pCm)
> ~~~
>
> 証明: `1/C + (C+1)/(pCm) = 1/C + km/(pCm) = 1/C + k/(pC) = (p+k)/(pC) = 4C/(pC) = 4/p`。

`p ≡ 1 (mod 4)` なので `p+4 ≡ 1 (mod 4)`。よって `p+4` が `3 (mod 4)` の素因子 `q` を
持てば `k = q`、`j = (p+4)/q ≡ 3 (mod 4)` と取れる。したがって

> **系 2.1.** `p + 4` が `3 (mod 4)` の素因子を持つ hard prime では ES が成り立つ。

`p < 4·10^6` の hard prime 8,710 個のうち 3,658 個（42.0%）にこれが適用でき、全件で
`4/p` と厳密一致することを確認した。

失敗するのは `p+4` の全素因子が `1 (mod 4)` の場合**のみ**である。
`p < 2·10^7` の hard prime 39,391 個で

```text
D=1 成功                     17,525 (44.5%)
p+4 が 3 mod 4 の素因子を持たない 21,866 (55.5%)
最小の 3 mod 4 因子が 20003 超        0
```

`k ≤ 20003` の打ち切りは一切効いていない（`code/tradeoff.cpp` の D=1 行と独立実装で一致）。

hard class は `h + 4 ∈ {5, 125, 173, 293, 365, 533}` で、これらの素因子は全て `1 (mod 4)`
である。つまり **hard class は `p+4` から小さい `3 (mod 4)` 素因子をあらかじめ排除している**。
一般の `n ≡ 1 (mod 4)` で「全素因子が `1 (mod 4)`」の密度は約 30% だが、hard class では
55.5% に上がるのはこのためである。

この失敗集合は Landau–Ramanujan 型で密度 `≍ 1/√(log p) → 0` なので、補題 2 だけで
**hard prime の密度 1 で ES が従う**。ただし saving は `1/√log` のみで、Vaughan の
`exp(-c(log x)^{2/3})` には遠く及ばない。合同条件では捕まらない集合が残る、という
点が本質である。

## 5. 何が言えたか / 次

- 証拠の約数部分は浅い（`D = 64` で `p<10^8` 全域）。難しさは shift `k` の探索範囲だけ。
- `cert(p)` は `p<10^9` で 395 以下、幾何平均 17.2 と極めて安定。
- `D = 1` 層は完全に解け、その失敗集合が Landau–Ramanujan 型集合として同定できた。

次に決めるべきは `D = 2, 4, 8` の各層の失敗集合が同様に同定できるかである。`D=1` が
「`p+4` の素因子の `mod 4` 類」で決まったように、各層が `p + c` 型の数の素因子の
character 条件で決まるなら、層を重ねた失敗集合の共通部分は
[fab sieve](../topics/08-external-nr-and-fab-sieve.md) の sieve dimension を
直接押し上げる。層ごとの失敗集合が独立に近ければ、`D ≤ 2^t` までの共通部分の密度は
`(log p)^{-t/2}` 程度まで落ちる勘定になる。
