## 1. 連続 shift 座標

shift を `q_j = 4j+3` とし、`N = (p+3)/4`、`C_{q_j} = (p+q_j)/4` と置くと

~~~
C_{q_j} = N+j.
~~~

したがって `q=3,7,11,15,...` を順に調べることは、連続整数
`N,N+1,N+2,...` の因数分解を調べることと同じである。

signed-box の target は次の形になると報告された。

- Type I: `D ≡ -(j+1) (mod q_j)`。この target からは `p` が消える。
- Type II: `D ≡ -C_{q_j} (mod q_j)`。

これは個別 shift の表を増やすより、連続整数列に沿った因数の character と
target 捕捉を研究するための座標である。なお、会話ではこの residual-numerator
座標と 2026 年の preprint との類似も指摘されたが、その文献の内容自体は本書で
独立検証していない。

## 2. q=11 の zero-slack branch と q=19 への cross-shift

### q=11 の branch 分類

既存の thin branch 条件のもとでは、`v_3(C_11)=1`、他の QR 因子は `1 mod 11`、
NR 因子は `2,6 mod 11`、NR valuation の合計は 2 以下と整理されている。
さらに NR-bearing combined zero-slack miss では

~~~
A_11 = {1,3,4},   K_11 \ A_11 = {5,9}.
~~~

NR valuation の合計を `E` とすると、miss に残る場合は

- `E=1` なら `p ≡ 2,6 (mod 11)`;
- `E=2` なら `p ≡ 1 (mod 11)`。

`E=2` では、`2 mod 11` と `6 mod 11` の NR 因子を一つずつ使う必要がある。
この分類は `p<10^8` の hard prime 6,199 状態で監査され、分類違反 0 と報告された。

### cross-shift 補題

hard prime では `p mod 5 ∈ {1,4}` かつ `(p/5)=+1`。もし `p ≡ 4 (mod 5)` なら
`5 | C_11` であり、5 は mod 11 の非自明 QR なので `A_11` を拡張する。
よって次の含意が得られる。

~~~
q=11 の NR-bearing zero-slack miss なら p ≡ 1 (mod 5)。
~~~

従って `5 | C_19` となり、hard class は

~~~
{1,121,169,289,361,529} から {1,121,361} (mod 840)
~~~

へ絞られる。この部分は、条件を明記した cross-shift の候補補題として live に
残す価値がある。

### class 121 での q=19 saturation

`p ≡ 121 (mod 840)` なら `p ≡ 2 (mod 7)` なので `7 | C_19` も強制される。
mod 19 では

~~~
{1,5,5^-1} = {1,5,4},
{1,7,7^-1} = {1,7,11}
~~~

であり、その積が `Q_19` 全体を埋める。したがってこの branch では、会話内の
結論は次の exact equivalence である。

~~~
q=19 が miss  ⇔ C_19 の全素因子が p-QR。
~~~

`p<10^8` の該当 branch 2,081 件では、p-NR 因子あり 1,371 件がすべて hit、
全因子 QR の 710 件がすべて miss、例外 0 と報告された。

## 3. 成功した detector と失敗した route

### k=15: 全 hard class の quadratic-nonresidue detector

combined miss に見えていた `pure H={1,2,4,8}` branch と thin 11-packet のうち、
後者は hard-prime の center 条件を入れると空になると整理された。場合分けは

- `p ≡ 4 (mod 15)` なら signed target は 11。11 mod 15 の因子があれば hit。
- `p ≡ 1 (mod 15)` なら `C_15 ≡ 4 (mod 15)`、target は 14。thin branch の
  outside center が 1、H-part center が 4 なので `4*11 ≡ 14 (mod 15)`。

その結果、会話内では次を range-free の同値として報告した。

~~~
k=15 の miss ⇔ 全ての r|C_15 が r mod 15 ∈ {1,2,4,8}
             ⇔ C_15 に p-NR 素因子がない。
~~~

`p<10^8` の全 hard prime 179,468 件の監査値は、exact miss 98,684、pure-H miss
98,684、non-pure miss 0、mismatch 0。これは強い計算的裏付けだが、最終的な
文献化には signed-box 定義と reciprocity transfer の完全な証明を添える必要がある。

### k=35: class 121, 361 の pure-support theorem

`p ≡ 121 (mod 840)` では mandatory seed `3 | C_35`、かつ `C_35 ≡ 4 (mod 35)`。
`(Z/35Z)^× ≃ C_12 × C_2` の exact closure では reachable state 394 個で、class 121
の center に一致する combined miss は 2 状態だけ、いずれも pure Jacobi `+1`
support だった。従って会話内の定理候補は

~~~
p ≡ 121 (mod 840) ⇒
k=35 の miss ⇔ C_35 の全素因子が p-QR。
~~~

同じ現象は class 361 にもある。6 hard class の closure atlas は次の通り。

| `h=p mod 840` | miss state | pure miss | non-pure miss |
|---:|---:|---:|---:|
| 1 | 12 | 4 | 8 |
| 121 | 2 | 2 | 0 |
| 169 | 6 | 3 | 3 |
| 289 | 3 | 2 | 1 |
| 361 | 3 | 3 | 0 |
| 529 | 6 | 4 | 2 |

従って `h=121,361` は exact pure-support、他の4 classでは同じ命題は偽、
という制御付きの整理になっている。class 121 の p<10^8 監査は 29,900 個で
miss 18,080、pure 18,080、non-pure miss 0、mismatch 0 と報告された。

### k=39: 機械的な一般化は失敗

class-conditioned seed を 2 または 10 とした exact closure では、

| seed | miss | `+1` miss | `-1` miss |
|---:|---:|---:|---:|
| 2 | 74 | 52 | 22 |
| 10 | 20 | 17 | 3 |

となった。mandatory seed だけで negative-character branch を消せるわけではなく、
`k=15` や `k=35` の完全消去を一般 k へ機械的に延長する仮説は支持されない。

## 4. q=23 から q=27/31 への route は棄却

q=19 の pure-QR survivor 710 件を q=23 で調べると、459 hit、247 pure-QR miss、
4 thin miss だった。4 件だけを見ると、`p mod 11=6` なら `11|C_27`、
`p mod 11=2` なら `11|C_31` となり、必ず次で hit するように見えた。

しかし `p<10^9` まで探索すると q=23 thin survivor は 61 件あり、
`p mod 11=1:5, 2:31, 6:25` に分布した。したがって

~~~
q=23 の thin miss は q=27 または q=31 へ必ず route する。
~~~

は反証済みである。少数例からの固定 route 推測を繰り返さないための負のデータ点。

最初の exact hit に必要な素因子方向の最小 support を、`p<10^8` の hard prime

| minimum support | 件数 |
|---:|---:|
| 0 | 7,082 |
| 1 | 153,245 |
| 2 | 18,785 |

従って 99.80% が support 2 以下、179,467/179,468 が support 3 以下で、唯一の

「大部分は容量で解け、少数の sparse alignment が本当の障害」という二相構造を
支持する。

## 6. 現在の作業仮説

個別の固定 shift を順番に増やすより、次の状態遷移を一般化するのが有望である。

~~~
thin state
  → prime-support alphabet の制限
  → hard class が強制する次 shift の因子
  → quadratic-character kernel の saturation
  → signed-box target の捕捉
~~~

q=11 → q=19 はこの流れの具体例で、q=23 → q=27/31 は固定 route として失敗した。
次に必要なのは「mandatory seed + exact center が negative-character miss を全消去する
条件」の群論的な判定であり、k=15、k=35 の一部、k=39 の失敗を最初の atlas として
比較することである。
