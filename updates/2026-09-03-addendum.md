## 1. external-NR cycle の単調降下は失敗

external quadratic-nonresidue factor を頂点、factor relation を辺とする cycle を
辿れば signed-box の failure が改善する、という仮説は反証された。

`p=3361` には

~~~
53 → 31 → 1103 → 1051 → 281 → 11 → 53
~~~

という 6-cycle があり、各頂点で squarefree aligned-shield が失敗する。したがって
`D(q)>D(r)` 型の単純な ranking function は作れない。親と子を同時に seed に入れる
案も `p<2·10^6` の 4,519 hard prime では seed-only hit が 243 件 (5.4%) に留まった。

これは cycle の存在そのものの否定ではなく、cycle から解への monotone descent が
ないという negative result である。

## 2. aligned-shield seed-only rule には初等的 no-go がある

external NR prime `q` と squarefree `s|210` に対し、`M=qs`、aligned shift `k_s` を
`k_s ≡ -p (mod 4M)` とする構成は、最終的に

~~~
k_s | A+B  または  k_s | 4B²Rn+1
~~~

という小さな divisibility sieve に落ちる。

さらに `q>632`、`(2/q)=-1`、`p≡1 (mod 840)`、`p≡2 (mod q)` と、各 `k_s` に
`p≡1 (mod k_s)` を課すと、Type I / Type II の両 target が `-1` になる。
q を denominator 側に使った `-1` hit は

~~~
q(uv-a)=2u+b
~~~

を満たす必要があるが、`u≤210`、`q>632` から右辺は q 未満となり矛盾する。
numerator 側も同様である。従ってこの条件では全ての `s|210` が seed-only miss。

この構成を任意個の q に CRT と Dirichlet で並べられるため、任意の N に対して
最初の N 個の external NR が全てこの限定 rule を失敗する hard prime が無限に存在する。
これは restricted seed-only rule に対する no-go theorem であり、full cofactor を含む
signed box や Erdős–Straus 予想そのものの反証ではない。

## 3. large defect は矛盾にならない

`C_q=(p+q)/4`、`R_q=R_q(C_q)`、`H_q=Stab(R_q)` とすると、signed exponent vector
の個数から `|R_q|≤τ(C_q²)`。従って

~~~
[ (Z/qZ)^× : H_q ] ≥ (q-1)/τ(C_q²).
~~~

固定 p で q を大きくすると `C_q≍q`、`τ(n)=n^{o(1)}` より index は
`q^{1-o(1)}` 以上になる。つまり巨大 defect index は大きな q でほぼ自動的に発生し、
counterexample 固有の異常とは言えない。

`p<2·10^6`、external `q<500` では external pair 約 11 万件中 exact miss 70,465、
その 97.8% で `H_q={1}`。`q<1000` でも miss の典型は stabilizer ではなく、
`C_q` の素因子が少なく box が疎なことだった。

| external q | exact miss率 | 平均 occupancy |
|---:|---:|---:|
| `<100` | 33.3% | — |
| `100–200` | 62.1% | — |
| `200–300` | 71.7% | — |
| `400–500` | 81.6% | — |
| `600–700` | 91.0% | — |
| `900–1000` | 90.7% | — |

q が大きいほど `τ(C_q²)` に対する modulus q の比が悪化するため、generic expansion
で rescue されると期待するのは逆方向である。

## 4. E_q=1 の normal form

external q の miss の大部分では、NR valuation が `E_q=1`。すなわち

~~~
C_q = rS,  (r/q)=-1,
~~~

で、S の全素因子は QR である。`Q_q=R_q(S)` とすると signed box は

~~~
R_q(C_q)=Q_q ∪ rQ_q ∪ r^{-1}Q_q.
~~~

この場合の combined miss は、会話内の normal form では QR subgroup 内の prescribed
inverse orbit を避ける条件に一致する。`q<1000` の E_q=1 external pair 189,896 件で
original exact 判定との mismatch は 0。さらに `S` の素因子が QR subgroup 全体を
生成するケースも 80.1% あり、典型的 failure は高次 character や subgroup 不足ではなく
exact placement の問題である。

## 5. class-specific detector 後の有限 signal

hard class ごとの exact detector roster を先に適用すると、`p<10^8` の hard prime
179,468 個のうち全 detector miss は 7,452 個。その 7,452 個は external prime shift
で全て hit し、必要最大 shift は `q=251`、最大例は `p=10,028,209`、`h=289`。

この集合では全件で最初の successful external shift `q*(p)` が

~~~
q*(p) < (log p)^2
~~~

を満たした。これは有力な有限 signal だが、least quadratic nonresidue と target
placement の両方を含むため、現時点では conjecture である。

stress test では `10^8<p<10^12` の 30,000 標本中 detector survivor 550 件が全て
external shift で hit（最大 q*=139、比率 0.197）、`10^12<p<10^15` の 5,000 標本中
survivor 73 件も全て hit（最大 q*=107、比率 0.090）。小さい external q を全て
QR にする adversarial congruence でも、最初の NR `q=103` または `191` で hit する例が
得られた。

## 6. prime-or-complement factor lemma

coprime `a,b` を固定し、

~~~
M=4ab,  L=a+bp,  t=-p (mod M)
~~~

とする。L から M と共通する prime-power を除いた M-unit part を N、`c=N (mod M)`
とする。target divisor は M と互いに素なので N の約数でなければならない。

`r|N` が

~~~
r ≡ t (mod M)
~~~

なら r 自身が admissible divisor。一方

~~~
r ≡ c t^{-1} (mod M)
~~~

なら complement `N/r` が t に一致する。従って exact coprime fab criterion から

~~~
fab(p,a,b)=0
⇒ 全 r|N が t と c t^{-1} を避ける。
~~~

これは有限群 closure や character theory を使わない、prime-or-complement の初等補題。
ただし、これだけでは ES の universal proof ではなく、linear form の forbidden
prime-factor classes を導くための補題である。

## 7. 小さい fab pair と sieve dimension

hard prime `p≡1 (mod 24)` では `(a,b)=(1,6),(6,1)` に対し `L` の中心は 7、target は
23、complement target は 17 (mod 24)。したがって

~~~
r|6p+1 または r|p+6,
r≡17,23 (mod 24)
~~~

なら解が得られる。counterexample は両 linear form の全素因子でこの2 residue class
を避ける必要がある。

この m=6 の2 pair と既存 q=3,7 filter を合わせると、平均 sieve dimension の候補は
`κ=2.5`。m=5 pair を足すと `κ=3` まで上がる。一般に m≤M の pair を足すと

~~~
κ(M) = 1 + 2 Σ_{m≤M} 1/φ(4m)
~~~

という発散候補が得られる。固定 M ごとの Selberg sieve を形式化すれば任意の
logarithmic saving が期待できるが、sieve parity と thin-but-nonempty wall が残るため、
これも ES の証明ではない。

## 現在地

今回の検証で、

- external-NR cycle の単純 monotone descent;
- bounded external-NR rank（aligned-shield seed-only rule）;
- large defect 自体を矛盾にする route;
- detector miss から target position を直接予測する route

は閉じた。一方で、full cofactor を含む signed box、prime-or-complement lemma、
small-fab sieve の組合せは残っている。次の本命は、`fab` の forbidden residue sieve を
完全な有限-M theorem にし、最後に sieve で落とせない薄い集合へ非 sieve 的な議論を
接続することである。
